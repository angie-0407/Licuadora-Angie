# Proyecto Licuadora

Este proyecto simula el funcionamiento de una licuadora controlada mediante un botón. Al hacer clic en el botón, la licuadora se enciende o apaga, y se reproducen sonidos e imagenes correspondientes.

## Funcionamiento

La licuadora tiene dos estados:
- **Apagada**: La licuadora está inactiva, no produce sonido, la imagen es estática.
- **Encendida**: La licuadora está en funcionamiento, emite el sonido propio de una licuadora y muesta un gif del proceso de licuado. 

### Sonidos
- Al presionar el botón para encender la licuadora, suena el sonido del botón y el sonido de la licuadora.
- Al apagar la licuadora, el sonido del botón se reproduce nuevamente, pero el sonido de la licuadora se detiene.

## Instrucciones de despliegue

1. **Requisitos previos**:
   - Un navegador web moderno (Chrome, Firefox, Edge, etc.) para probar el funcionamiento.
   - Asegúrate de tener los archivos de sonido disponibles en la misma carpeta donde se encuentra el archivo HTML.

2. **Pasos para desplegar**:
   - Clona este repositorio o descarga los archivos del proyecto.
   - Abre el archivo HTML en tu navegador.
   - Haz clic en el botón para controlar la licuadora.
